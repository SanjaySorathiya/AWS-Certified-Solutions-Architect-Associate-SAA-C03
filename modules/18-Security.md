###  **Security Services**

| Service | What it Does | Layer | Exam Scenario |
| :--- | :--- | :--- | :--- |
| **AWS WAF (Web Application Firewall)** | • Protects web apps from common exploits and malicious bots.<br>• Filters requests using custom rules (IPs, HTTP headers, URI strings).<br>• Blocks SQL injection (SQLi) and Cross-Site Scripting (XSS). | Layer 7 (CloudFront, ALB, API Gateway, AppSync, Cognito) | • "Block SQL injection"<br>• "Protect against OWASP Top 10"<br>• "Geo-block specific countries"<br>• "Rate-limit brute force attacks" |
| **AWS Shield Standard (DDoS protection)** | • Automatic, always-on DDoS protection.<br>• Defends against common Layer 3 and 4 network/transport layer attacks.<br>• Included for all AWS customers at no additional cost. | Layers 3 / 4 (All AWS services) | • "Automatic DDoS protection with zero configuration or charge" |
| **AWS Shield Advanced** | • Enhanced DDoS protection with specialized mitigation.<br>• Includes 24/7 access to the DDoS Response Team (DRT).<br>• Provides cost protection to absorb scaling spikes from attacks. | Layers 3 / 4 / 7 (CloudFront, Route 53, ALB, NLB, EIP) | • "Sophisticated, large-scale DDoS attacks"<br>• "Financial protection from scaling fees"<br>• "Direct support from security experts (DRT)" |
| **AWS Firewall Manager** | • Centrally configures and manages firewall rules across AWS Organizations.<br>• Enforces uniform security policies for WAF, Shield Advanced, Network Firewall, and VPC Security Groups. | Multi-account / Org-level | • "Apply uniform WAF rules across all member accounts"<br>• "Centralized management of security groups" |
| **Amazon GuardDuty** | • Continuous threat detection using machine learning and anomaly detection.<br>• Monitors VPC Flow Logs, CloudTrail logs, DNS logs, S3 data events, and EKS audit logs.<br>• Does not block threats; raises security findings. | Account-level / Intelligent threat detection | • "Detect cryptomining activity"<br>• "Identify suspicious API activity or compromised credentials"<br>• "Continuous threat monitoring with zero performance impact" |
| **Amazon Inspector** | • Automated vulnerability management service.<br>• Scans EC2 instances, ECR container images, and Lambda functions.<br>• Identifies software vulnerabilities (CVEs) and unintended network exposure. | Workload-level | • "Scan EC2 instances or container images for software vulnerabilities"<br>• "Automated CVE scanning on deployment" |
| **Amazon Macie** | • Automated data privacy and security service using machine learning.<br>• Discovers, classifies, and protects sensitive data (PII) stored in Amazon S3. | S3 Data Level | • "Identify PII (e.g., SSN, credit cards) in S3"<br>• "Ensure GDPR/PCI compliance for S3 data" |
| **AWS Security Hub** | • Central hub for security posture management and compliance checks.<br>• Aggregates and normalizes alerts/findings from GuardDuty, Inspector, Macie, IAM Access Analyzer, and AWS Config. | Cross-service / Multi-account | • "Single pane of glass for multi-account security posture"<br>• "Compliance checks against CIS/PCI-DSS standards" |
| **AWS Network Firewall** | • Fully managed, stateful network firewall for VPC traffic.<br>• Performs deep packet inspection, URL filtering, and implements Suricata-compatible IPS rules. | VPC Level | • "Deep packet inspection for VPC traffic"<br>• "IPS/IDS in VPC"<br>• "Restrict outbound traffic to specific domain names" |
| **AWS Secrets Manager** | • Stores, retrieves, and automatically rotates credentials and API keys.<br>• Built-in rotation integration with RDS, Redshift, and DocumentDB using AWS Lambda. | Application secrets | • "Rotate database passwords automatically"<br>• "Prevent hardcoded credentials in application code" |
| **AWS Systems Manager Parameter Store** | • Secure, hierarchical storage for configuration data, licenses, and secrets.<br>• Free for standard tier; does not offer native auto-rotation (requires custom Lambda setup). | Config & secrets | • "Store hierarchical configuration data"<br>• "Cost-effective configuration storage without native rotation" |
| **AWS KMS (Key Management Service)** | • Secure key management service integrated with 100+ AWS services.<br>• Creates and controls Customer Managed Keys (CMKs) for envelope encryption.<br>• FIPS 140-2 Level 2 compliant; keys are shared on hardware (multitenant). | Key Management | • "Customer managed cryptographic keys"<br>• "Envelope encryption with AWS service integration"<br>• "Automatic annual key rotation" |
| **AWS CloudHSM (hardware security modules - HSMs)** | • Dedicated, single-tenant hardware security module (HSM) under customer control.<br>• Customer manages keys, users, and cryptographic operations entirely.<br>• FIPS 140-2 Level 3 compliant; physical hardware is isolated. | Hardware key protection | • "FIPS 140-2 Level 3 regulatory requirements"<br>• "Exclusive, direct key control via industry standards (PKCS#11, JCE)" |

<br>

| ⚠️ EXAM TRAP: Secrets Manager vs Parameter Store: Secrets Manager costs ~$0.40/secret/month but auto-rotates credentials and is designed for secrets. Parameter Store is free for standard parameters but has no auto-rotation (requires triggering custom Lambda yourself). For SAA-C03: "auto-rotate database credentials" → AWS Secrets Manager. |
| :--- |

| 🧠 MNEMONIC: GuardDuty = Guard dog (threat DETECTION). Inspector = Home inspector (vulnerability SCANNING). Macie = Mac & Privacy (PII/data CLASSIFICATION). These are three different jobs: detect threats, find vulnerabilities, classify data. |
